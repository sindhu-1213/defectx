# DefectX sample images

These six files are copies of existing product photographs from
[`../examples/`](../examples/). They are VisA-related dataset examples, not
screenshots or generated images. Filenames are preserved.

| File | Product | Source dataset label |
|---|---|---|
| `candle_Normal_0085.JPG` | Candle | Normal |
| `candle_Anomaly_009.JPG` | Candle | Anomaly |
| `capsules_Normal_033.JPG` | Capsules | Normal |
| `capsules_Anomaly_000.JPG` | Capsules | Anomaly |
| `pcb2_Normal_0041.JPG` | PCB 2 | Normal |
| `pcb2_Anomaly_001.JPG` | PCB 2 | Anomaly |

The labels above are carried in the source dataset filenames and are not
predictions from DefectX. The original Visual Anomaly (VisA) dataset and the
project's derived Roboflow export are identified as CC BY 4.0 in the
[repository dataset licensing notes](../../README.md#licensing-and-redistribution).
The images here are unmodified copies selected for the application gallery.
Please retain the VisA citation and follow the dataset attribution terms when
redistributing them; see the [repository citation and licensing documentation](../../README.md#dataset-citation-and-licensing).
